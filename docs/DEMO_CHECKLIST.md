# Demo Video Checklist (1 Minute)

## Pre-Recording Setup
- [ ] Close unnecessary browser tabs
- [ ] Set game to fullscreen (F11)
- [ ] Ensure 60 FPS performance
- [ ] Test audio recording (if adding narration)
- [ ] Prepare screen recording software (OBS, ShareX, etc.)

## Recording Script

### Segment 1: Title Screen (0:00-0:10)
- [ ] Show animated title "QUANTUM FLUX"
- [ ] Highlight "SOFT-BODY PHYSICS ENGINE v2.0"
- [ ] Show system status indicators
- [ ] Display animated energy core
- [ ] Press Enter to start

**Narration**: "Quantum Flux - A soft-body physics platformer with time-echo mechanics"

### Segment 2: Basic Movement (0:10-0:20)
- [ ] Demonstrate WASD movement
- [ ] Show jump mechanics
- [ ] Display HUD with controls
- [ ] Show soft-body jiggle animation
- [ ] Interact with bounce pad

**Narration**: "Navigate using WASD with realistic jiggle physics"

### Segment 3: Time-Echo Mechanic (0:20-0:35)
- [ ] Press Q to start recording
- [ ] Show "RECORDING TIMELINE" indicator
- [ ] Perform movement sequence (jump, move, bounce)
- [ ] Wait for "TIMELINE CAPTURED" message
- [ ] Press E to deploy quantum echo
- [ ] Show ghost replaying exact movements

**Narration**: "Record 5 seconds, then spawn quantum echoes that replay your actions"

### Segment 4: Physics Showcase (0:35-0:45)
- [ ] Bounce on bounce pad (orange)
- [ ] Land on jelly platform (purple wobble)
- [ ] Touch elastic wall (cyan push-back)
- [ ] Walk through slime pool (green slowdown)
- [ ] Jump on wave platform (blue moving)

**Narration**: "Five unique physics elements create dynamic challenges"

### Segment 5: Level Complete (0:45-0:55)
- [ ] Navigate to exit (green square)
- [ ] Show level transition
- [ ] Display "PHASE 2" indicator
- [ ] Show intensity percentage increase
- [ ] Demonstrate chromatic aberration effect

**Narration**: "Eight progressively challenging phases with increasing intensity"

### Segment 6: Victory/Credits (0:55-1:00)
- [ ] Skip to final level (press N multiple times)
- [ ] Complete level or show victory screen
- [ ] Display celebration particles
- [ ] Show "ALL 8 PHASES COMPLETED"
- [ ] Show credits/attribution

**Narration**: "Built in 24 hours with Kaboom.js and TypeScript"

## Post-Recording
- [ ] Trim to exactly 60 seconds
- [ ] Add background music (optional, royalty-free)
- [ ] Add text overlays for key features
- [ ] Export in 1080p or 720p
- [ ] Test playback quality
- [ ] Upload to YouTube/Drive
- [ ] Share link in Telegram group

## Key Features to Highlight
✅ Soft-body jiggle physics  
✅ Time-echo recording/replay  
✅ 5 unique physics elements  
✅ 8 challenging levels  
✅ Progressive visual effects  
✅ Futuristic UI design  

## Quick Demo Tips
- Keep mouse movements smooth
- Don't die on spikes during recording
- Show multiple echoes simultaneously
- Demonstrate echo + physics interaction
- Keep narration concise and energetic

## Backup Plan
If recording goes wrong:
1. Have 2-3 practice runs first
2. Record multiple takes
3. Use best segments from each
4. Add text overlays to explain features
5. Use gameplay screenshots as fallback

## File Export Settings
- **Format**: MP4 (H.264)
- **Resolution**: 1920x1080 or 1280x720
- **Frame Rate**: 30 or 60 FPS
- **Bitrate**: 5-10 Mbps
- **Audio**: AAC 128-192 kbps (if narration)

---

**Remember**: Show, don't tell! Let the gameplay speak for itself.
